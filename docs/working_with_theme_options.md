A common need for a theme is to have a place to store global settings.
This theme uses [Advanced Custom Fields Pro :arrow_upper_right:](https://www.advancedcustomfields.com/pro/) to create an options page for this purpose.
The default location for the theme settings page is in Settings -> Theme Options.

Every class that inherits from [`Component` :arrow_upper_right:](/php/components/class-component.php) is has a built-in easy way to define theme options.

## How to use

Here are the steps to create a new theme option and register it with your component.

### 1. Add a property

Declare a property in your class that will store your theme option:

```php
/**
 * @var Theme_Option $enable_my_feature Enable My Feature.
 */
protected Theme_Option $enable_my_feature;
}
```

### 2. Initialize the `Theme_Option`

This should be done in your `Component`'s constructor so that the property is as soon as possible.

The first argument is the option key that will be used for the ACF's `key` and `name` properties.
Make sure it is unique. The best way to do this is to use the `get_option_key` method that is available on the `Component` class.
It will create a key based on the full class name (including namespace) and a property name that you pass to the `get_option_key` method.

The second argument is an array of field options that will be passed through to ACF (check out the [ACF docs :arrow_upper_right:](https://www.advancedcustomfields.com/resources/register-fields-via-php/) for a full reference).
Keep in mind that you should not provide the `key` and `name` properties in this array, as they will be automatically generated by the `Theme_Option` class.

```php
$this->enable_my_feature = new Theme_Option(
	$this->get_option_key( 'enable_my_feature' ),
	[
		'label' => __( 'Enable My Feature', 'eutopia-theme' ),
		'type'  => 'true_false',
	]
);
```

### 3. Register the theme options

This should be done in your `Component`'s constructor.

The first argument is the label that will be used for the options group.

The second argument is an array of `Theme_Option` instances that were defined in the previous step.

```php
$this->register_theme_options(
	__( 'My Component Settings', 'eutopia-theme' ),
	[
		$this->enable_my_feature,
	],
);
```

### 4. Provide a getter method

If the theme option is supposed to be used outside the component, provide a getter method for it:

```php
/**
 * Check whether my feature is enabled.
 *
 * @return bool
 */
public function get_enable_my_feature(): bool {
	return $this->enable_my_feature->get();
}
```

For reference, here is the full implementation:

```php
<?php
/**
 * Eutopia_Theme\Components\My_Component class.
 *
 * @package Eutopia_Theme\Components
 */

namespace Eutopia_Theme\Components;

use Eutopia_Theme\Theme_Option;

/**
 * My_Component class.
 */
class My_Component extends Component {
	/**
	 * @var Theme_Option $enable_my_feature Enable My Feature.
	 */
	protected Theme_Option $enable_my_feature;

	/**
	 * Constructor.
	 */
	public function __construct() {
		$this->enable_my_feature = new Theme_Option(
			$this->get_option_key( 'enable_my_feature' ),
			[
				'label' => __( 'Enable My Feature', 'eutopia-theme' ),
				'type'  => 'true_false',
			],
		);

		$this->register_theme_options(
			__( 'My Component Settings', 'eutopia-theme' ),
			[
				$this->enable_my_feature,
			],
		);
	}

	/**
	 * Check whether my feature is enabled.
	 *
	 * @return bool
	 */
	public function get_enable_my_feature(): bool {
		return $this->enable_my_feature->get();
	}
}
```
